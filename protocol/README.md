# Browser Capture API Mirror

`browser-capture.openapi.yaml` is an exact checked-in mirror of Increader's
canonical Browser Capture OpenAPI document.

- `PROVENANCE.json` records the Increader source commit, generator, and SHA-256
  digest of each mirrored input.
- `fixtures/` contains representative Bookmark Lookup and Capture Package
  documents.
- `../src/protocol/generated/browser-capture.ts` is generated by
  `openapi-typescript`.

Run `npm run protocol:check` to verify input hashes and generated types. Updating
the mirror is an intentional cross-repository change; builds do not fetch the
Increader repository.

Browser Capture adds two operations to Increader's normal authenticated API:

- exact owned Bookmark Lookup for one fragment-free Capture Source URL;
- multipart Capture Package import using `manifest`, `document`, and captured
  image parts.

Both accept the same authenticated User session as the normal client. There is
no extension-specific credential or authorization protocol.
