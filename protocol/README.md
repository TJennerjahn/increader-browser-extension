# Browser Capture Protocol Mirror

`browser-capture.openapi.yaml` is a checked-in public mirror of Increader's
canonical unversioned Browser Capture OpenAPI document.

- `PROVENANCE.json` records the exact Increader source commit, generator, and
  SHA-256 digest of every mirrored input.
- `fixtures/` contains canonical compatible and incompatible discovery and
  pairing documents.
- `../src/protocol/generated/browser-capture.ts` is generated by
  `openapi-typescript`.

Run `npm run protocol:check` to verify input hashes and prove generation leaves
no diff. The check uses only files in this repository. Updating the mirror is an
intentional cross-repository change, not a build-time fetch or shared package
release.

The `info.version: unversioned` value satisfies OpenAPI metadata requirements;
it is not a protocol/schema version. Discovery uses a stable protocol identity,
additive capabilities, tolerant readers, and effective limits. A genuinely
breaking change requires a new endpoint or media type.

Pairing distinguishes Account Identity operations from credential operations:
approval and account-managed revocation use the existing signed-in context;
exchange, renewal, and installation disconnect explicitly omit cookies and use
PKCE or the rotating opaque renewal credential.

Browser Capture Bookmark Lookup accepts only the short-lived capture-scoped
access token and compares one fragment-free Capture Source URL exactly. It
returns only `exists` plus an owned Bookmark identifier/title when present; it
is not a library search or URL-equivalence API. The source URL travels in a
minimal POST body so it does not enter ordinary request targets or access logs.

Text-only Browser Capture import sends one immutable unversioned package as
`multipart/form-data` with JSON `manifest` and UTF-8 `document` parts. The
extension allocates a Capture ID only after explicit Import, stages the
normalized live top-level DOM, and supplies no captured image binary parts in
this slice. Increader returns its normal `BookmarkResponse` with `201` for a
created Bookmark or `200` for the recorded existing/replay outcome.
