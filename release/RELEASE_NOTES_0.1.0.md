# Increader Browser Capture 0.1.0

Initial internal release for Chrome and Firefox 140+.

- Pair with Increader Cloud or one self-hosted instance through explicit
  approval and rotating capture-only credentials.
- Check the exact active URL for an existing owned Bookmark.
- Capture the live top-level HTML page and bounded raster images only after
  Import.
- Preserve interrupted transfers for explicit same-package Retry; never retry
  automatically.
- Open created or existing Bookmarks in Reader Mode.
- Disconnect or replace the paired installation without retaining multiple
  destinations.

This release contains no telemetry, remote code, incognito access, broad
publisher permissions, Safari/mobile support, or PDF capture.
