# Increader 0.1.0

Initial internal release for Chrome and Firefox 140+.

- Sign in to Increader Cloud with Google or email and password, or use a normal
  self-hosted account.
- Check the exact active URL for an existing owned Bookmark.
- Capture the live top-level HTML page and bounded raster images only after
  Import.
- Preserve interrupted transfers for explicit same-package Retry.
- Open created or existing Bookmarks in Reader Mode.
- Sign out through the account provider's normal session flow.

This release contains no separate extension authorization scheme, telemetry,
remote code, incognito access, persistent publisher permissions, Safari/mobile
support, or PDF capture.
