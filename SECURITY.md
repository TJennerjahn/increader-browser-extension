# Security Policy

Please report vulnerabilities through this repository's private GitHub Security
Advisory flow. Do not open a public issue for credential exposure, origin
permission bypass, active-content injection, Capture Package tampering, or
similar security-sensitive behavior.

Include the affected browser/version, extension version or commit, Increader
instance type, reproducible steps using synthetic content, and expected impact.
Do not attach real passwords, session/access tokens, authenticated publisher
content, or a browser profile.

The latest development branch is the supported security line until the first
internal release is tagged. Security fixes may reject unsafe inputs immediately
even when normal additive protocol compatibility would retain older inputs.
