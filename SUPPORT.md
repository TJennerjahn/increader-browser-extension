# Support

Browser Capture support is handled through the
[Increader issue tracker](https://github.com/TJennerjahn/Increader/issues).
Include the extension version, Chrome or Firefox version, Cloud or self-hosted
destination, and synthetic reproduction steps. Never post credentials,
authenticated publisher content, or browser-profile data.

Security reports must use the private process in [SECURITY.md](SECURITY.md).
General Increader documentation and self-hosting support live in the main
Increader repository.
